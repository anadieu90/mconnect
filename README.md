# Missèbo Connect - Application de marché en ligne

Cette application permet de numériser le marché de Missèbo à Cotonou (Bénin) en respectant ses spécificités culturelles.

## Comment utiliser cette application

1. Créez un nouveau dépôt GitHub
2. Ajoutez ces 4 fichiers dans votre dépôt :
   - `index.html`
   - `style.css`
   - `script.js`
   - `README.md`
3. Activez GitHub Pages dans les paramètres de votre dépôt :
   - Allez dans "Settings" > "Pages"
   - Sélectionnez la branche "main" et le dossier racine "/"
   - Cliquez sur "Save"

L'application sera disponible à l'adresse : `https://votre-nom-utilisateur.github.io/votre-nom-depôt/`

## Fonctionnalités principales

- Page d'accueil avec carousel publicitaire
- Recherche de produits par catégorie
- Détails des produits avec possibilité de marchander
- Paiement en plusieurs tranches (tontine)
- Espace vendeur
